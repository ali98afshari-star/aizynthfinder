# AiZynthFinder — راهنمای فارسی

> 📖 نسخه انگلیسی این راهنما: [README.md](README.md) — این فایل، راهنمای فارسی همان ابزار است.

## AiZynthFinder چیست؟

AiZynthFinder یک ابزار متن‌باز برای **برنامه‌ریزی سنتز معکوس (Retrosynthetic Planning)** است؛ یعنی وقتی یک مولکول هدف به آن بدهید، به‌صورت بازگشتی آن را به پیش‌سازهای ساده‌تر می‌شکند تا در نهایت به موادی برسد که «قابل خرید» هستند. به زبان ساده: شما مولکول دارویی را که می‌خواهید بسازید می‌دهید، و ابزار مسیرهای ممکن ساخت آن را از مواد اولیه در دسترس پیشنهاد می‌دهد.

### چطور کار می‌کند؟

- **جستجوی درختی مونت‌کارلو (MCTS):** مولکول هدف را قدم‌به‌قدم به قطعات کوچک‌تر تجزیه می‌کند، مثل یک درخت که هر شاخه‌اش یک واکنش است.
- **شبکه عصبی سیاست‌گذاری (Policy Network):** مدلی که روی میلیون‌ها واکنش ثبت‌شده در پایگاه ثبت اختراعات آمریکا (USPTO) آموزش دیده و در هر مرحله محتمل‌ترین پیش‌سازها را پیشنهاد می‌کند.
- **انبار مواد (Stock):** فهرستی از مواد قابل خرید (مثلاً از کاتالوگ ZINC) که مسیر فقط وقتی «حل‌شده» محسوب می‌شود که همه برگ‌های نهایی‌اش در این انبار باشند.
- **فیلتر واکنش (اختیاری):** یک مدل دوم که واکنش‌های پیشنهادشده را از نظر شدنی بودن (feasibility) غربال می‌کند.

نتیجه، چند مسیر سنتز مرتب‌شده با امتیاز است که می‌توانید آن‌ها را به‌صورت JSON، تصویر یا گزارش تحلیلی بگیرید.

## به چه دردی می‌خوره؟ (برای یک داروساز ایرانی)

- **ارزیابی سنتزپذیری:** قبل از اینکه روی یک مولکول جدید یا یک داروی ژنریک وقت بگذارید، ببینید اصلاً مسیر سنتز معقولی برایش وجود دارد یا نه؛ مولکول‌های بدون مسیر را زود از فهرست گزینه‌ها حذف کنید.
- **طراحی مسیر ساخت داروی ژنریک:** برای یک داروی هدف، ببینید از چه پیش‌سازهایی و با چند مرحله می‌شود به آن رسید و کدام مسیر کوتاه‌تر و کم‌هزینه‌تر است.
- **شناسایی بلوک‌های ساختمانی (Building Blocks):** برگ‌های نهایی هر مسیر، همان مواد اولیه‌ای هستند که باید تهیه شوند؛ این فهرست نقطه شروع خوبی برای بررسی تأمین‌کننده‌هاست.
- **آموزش و پژوهش:** برای دانشجویان داروسازی و شیمی دارویی، یک آزمایشگاه مجازی برای فهم سنتز معکوس و تمرین روی مولکول‌های واقعی دارویی.
- **تکمیل زنجیره طراحی دارو با هوش مصنوعی:** وقتی یک عامل هوشمند مولکول جدیدی طراحی می‌کند (مثلاً با REINVENT)، AiZynthFinder آخرین حلقه زنجیره است: «آیا این مولکول اصلاً ساخته می‌شود؟»

### چه چیزی نیست؟

- **منبع اطلاعات دارویی نیست:** دوز، تداخل، اندیکاسیون و قیمت نمی‌دهد؛ برای این‌ها باید سراغ منابع دارویی معتبر رفت.
- **جایگزین قضاوت شیمی‌دان نیست:** مسیرهای پیشنهادشده را یک شیمی‌دان آلی باید از نظر شرایط واکنش، بازده، ایمنی و خلوص بررسی کند.
- **بازار ایران را نمی‌شناسد:** انبار پیش‌فرض آن کاتالوگ‌های بین‌المللی (مثل ZINC) است، نه بازار ایران. اینکه یک پیش‌ساز در ایران موجود است یا نه، باید جداگانه بررسی شود.

## پیش‌نیازها

- لینوکس، ویندوز یا مک (توسعه و تست اصلی روی لینوکس انجام شده)
- پایتون ۳٫۱۰ تا ۳٫۱۲ (توصیه: محیط conda یا venv جدا)
- برای اجرای کامل، سه چیز لازم است:
  1. **فایل انبار (Stock)** — فهرست مواد قابل خرید
  2. **مدل سیاست انبساط (Expansion Policy)** — شبکه عصبی پیشنهاد پیش‌ساز
  3. **مدل فیلتر (اختیاری)** — غربال واکنش‌ها

این فایل‌ها همراه کد نیستند و باید دانلود شوند (حجمشان زیاد است؛ بخش دانلود را ببینید).

## نصب

### نصب برای کاربر نهایی

```bash
conda create "python>=3.10,<3.13" -n aizynth-env
conda activate aizynth-env
python -m pip install aizynthfinder[all]
```

برای نصب سبک‌تر (بدون همه امکانات جانبی):

```bash
python -m pip install aizynthfinder
```

### نصب برای توسعه‌دهنده (از روی همین ریپو)

```bash
conda env create -f env-dev.yml
conda activate aizynth-dev
poetry install --all-extras
```

## دانلود مدل‌ها و فایل انبار

بعد از نصب، فایل‌های داده را با دستور زیر بگیرید (این دستور یک پوشه می‌سازد و داخلش `config.yml` آماده می‌کند):

```bash
download_public_data my_folder
```

فایل‌ها از Zenodo و figshare دانلود می‌شوند؛ چون حجمشان زیاد است، کمی صبر کنید. فایل `config.yml` ساخته‌شده همان چیزی است که در ادامه به ابزار می‌دهید.

## استفاده

### خط فرمان

```bash
aizynthcli --config config_local.yml --smiles smiles.txt
aizynthapp --config config_local.yml
```

`smiles.txt` فایلی است که در هر خط یک SMILES از مولکول هدف دارد. `aizynthapp` نسخه گرافیکی ابزار است.

### استفاده در پایتون

```python
from aizynthfinder.aizynthfinder import AiZynthFinder

finder = AiZynthFinder(configfile="config.yml")
finder.target_smiles = "CC(=O)NC1=CC=C(C=C1)O"  # پاراستامول
finder.prepare_tree()
finder.tree_search()
finder.build_routes()

for route in finder.routes:
    print(route.to_json())
```

### سرور MCP برای عامل‌های هوشمند (ویژه این ریپو)

در پوشه `pharmacy-mcp/` یک سرور MCP آماده است که همین موتور را در قالب ابزارهای استاندارد Model Context Protocol در اختیار عامل‌های هوشمند می‌گذارد (برنامه‌ریزی سنتز، امتیازدهی مسیر، بررسی بلوک‌های ساختمانی، اعتبارسنجی SMILES). راهنمای نصب و اجرا در `pharmacy-mcp/README.md` است و مهارت استفاده از آن در `skills/aizynthfinder/SKILL.md` آمده است.

## خروجی‌ها

برای هر مولکول هدف، ابزار گزارش‌های ساخت‌یافته می‌دهد:

- **مسیرها (Routes):** به‌صورت JSON یا تصویر درختی؛ هر مسیر شامل واکنش‌ها، واسطه‌ها و برگ‌های نهایی (بلوک‌های ساختمانی) است.
- **آمار جستجو:** تعداد مسیرهای حل‌شده، بهترین امتیاز، عمق درخت و زمان جستجو.
- **وضعیت حل‌شدن:** مسیری «حل‌شده» است که همه بلوک‌های نهایی‌اش در انبار مواد باشند.

## محدودیت‌ها — لطفاً قبل از اعتماد، بخوانید

- **مدل‌ها از داده‌های USPTO یاد گرفته‌اند:** واکنش‌های قدیمی یا نایاب در مقالات جدید، یا واکنش‌های خاص یک آزمایشگاه، ممکن است پوشش داده نشده باشند.
- **«حل‌شده» یعنی قابل خرید، نه یعنی آسان:** اینکه پیش‌سازی در کاتالوگ ZINC هست، به معنی در دسترس بودن آن در ایران، قیمت مناسب یا خلوص دارویی نیست.
- **بدون بررسی انسانی استفاده نکنید:** مسیر پیشنهادی یک نقطه شروع برای شیمی‌دان است، نه دستورالعمل آماده آزمایشگاه.
- **نسخه داده‌ها مهم است:** این ابزار عکس‌برداری از دانش تا یک مقطع زمانی است؛ نتایج را با منابع روز چک کنید.
- **مصرف محاسباتی:** جستجوی درختی برای مولکول‌های بزرگ زمان‌بر است؛ برای شروع، محدودیت تکرار و زمان را کم بگذارید.
